# SMT / PCB Manufacturing Domain Specification

## 1. Overview of PCB Assembly (PCBA) & Surface Mount Technology (SMT)

Electronics manufacturing relies on **Surface Mount Technology (SMT)** to assemble components onto bare **Printed Circuit Boards (PCBs)**. Modern SMT lines are high-speed, highly automated assembly lines operating at precision tolerances (down to sub-millimeter component pitch).

```
[ Bare PCB Board ] 
       │
       ▼
1. Solder Paste Printing ──► [ SPI: 3D Solder Paste Inspection ]
       │
       ▼
2. Pick & Place Machine  ──► [ Component Placement ]
       │
       ▼
3. Reflow Oven           ──► [ Metallurgical Bonding ]
       │
       ▼
4. Post-Reflow Inspection ──► [ AOI / AXI Inspection ]
       │
       ▼
5. Electrical Testing     ──► [ ICT / FCT Functional Test ]
       │
       ▼
[ Final Assembly / Box Build ]
```

### Key Stages of the SMT Process
1. **Solder Paste Printing**: A precision stencil applies lead-free or leadded solder paste onto PCB copper pads.
2. **Solder Paste Inspection (SPI)**: 3D optical sensors measure solder paste volume, height, area, and alignment on every pad before component placement.
3. **Component Pick and Place (Chip Shooters & Placement Machines)**: Vacuum nozzles pick Surface Mount Devices (SMDs)—such as 0201/01005 resistors, capacitors, Integrated Circuits (ICs), Quad Flat Packages (QFPs), and Ball Grid Arrays (BGAs)—from component reels and place them onto paste-covered pads at speeds of up to 100,000 components per hour.
4. **Reflow Soldering**: The populated board travels through a multi-zone conveyor furnace. Controlled thermal zones melt the solder paste, forming solid metallurgical intermetallic bonds between component leads and board pads.
5. **Automated Optical Inspection (AOI) & Automated X-ray Inspection (AXI)**: High-resolution camera arrays (AOI) inspect 2D/3D surface geometry, while X-ray inspection (AXI) penetrates beneath opaque packages (BGAs/QFNs) to inspect hidden solder joint integrity.
6. **Testing (ICT/FCT)**: Bed-of-nails In-Circuit Test (ICT) and Functional Circuit Test (FCT) verify electrical continuity, component values, and firmware functionality.

## 2. Where Defects Occur & Inspection Technologies

Defects in SMT manufacturing stem from mechanical, thermal, material, or operator variables.

### Defect Taxonomy
| Category | Defect Type | Primary Cause | Typical Detection Stage |
| :--- | :--- | :--- | :--- |
| **Solder Paste** | Insufficient / Excessive Paste | Clogged stencil apertures, improper squeegee pressure | SPI |
| **Solder Paste** | Paste Bridging | Stencil misalignment, improper snap-off distance | SPI |
| **Placement** | Misaligned / Shifted Component | Worn nozzle tip, feeder vibration, improper placement force | Pre-Reflow AOI / Post-Reflow AOI |
| **Placement** | Missing Component | Feeder pick failure, nozzle vacuum drop | Pre-Reflow / Post-Reflow AOI |
| **Placement** | Polarity Inversion / Wrong Part | Reel loaded incorrectly by operator | Post-Reflow AOI |
| **Reflow** | Tombstoning | Asymmetric thermal mass, unbalanced solder paste volume | Post-Reflow AOI |
| **Reflow** | Solder Bridging (Short Circuit) | Excessive paste, thermal slump, component lead skew | Post-Reflow AOI / ICT |
| **Reflow** | Cold / Grainy Solder Joint | Reflow temperature profile thermal soak deficiency | Post-Reflow AOI |
| **Hidden Joint** | Solder Voids / Head-in-Pillow (HiP) | Component oxidation, thermal profile mismatch, BGA warpage | AXI |

## 3. The Quality Incident & The Engineering Challenge

### Difference Between Defect Flag & Quality Incident
- **Defect Flag**: An individual automated flag generated by an AOI machine during routine board scanning (e.g., "Board 140, C17 shifted by 0.15mm").
- **Quality Incident**: A systemic, recurring, or high-severity quality event that exceeds statistical process thresholds (e.g., "Batch B-24017 on Line 3 exhibits a 12% tombstoning defect rate at C17 across the last 30 boards").

### Disparate Data Silos in Factory Environment
When a quality incident occurs, a Quality Engineer (QE) must manually aggregate information scattered across isolated enterprise databases and files:

```text
       +-----------------------------------------------------+
       |                   Quality Engineer                  |
       +--------------------------+--------------------------+
                                  |
    +-----------------+-----------+-----------+-----------------+
    |                 |                       |                 |
    ▼                 ▼                       ▼                 ▼
[ AOI/SPI Database ]  [ MES / ERP Database ]  [ Machine Logs ]  [ Document Store ]
- Inspection Images   - Batch B-24017         - Placer Nozzle 3 - SOP-QUAL-042
- Defect Coordinates  - Part # ECU-2026       - Feeder tension  - IPC-A-610 Class 3
- Confidence Scores   - Operator ID           - Reflow Profile  - Machine Manual
```

### Why This is a Real Business Problem
1. **High Cost of Downtime**: SMT production line downtime costs between **$10,000 and $50,000 per hour**. Delayed root-cause diagnosis halts production or risks generating massive scrap.
2. **Escaped Defects & Warranty Recalls**: Unresolved component defects that bypass factory testing lead to field failures in automotive ECUs, medical devices, or aerospace electronics, causing multi-million dollar product recalls.
3. **Manual Analysis Bottlenecks**: Engineers spend 70%+ of their time querying different databases, reading PDF SOPs, and cross-referencing timestamps, leaving little time for preventive action.

## 4. ForgeSight AI Value Proposition & Human-in-the-Loop Boundaries

ForgeSight acts as a **Multimodal Manufacturing Intelligence Platform**. It connects inspection visual evidence with production telemetry, historical maintenance logs, component lot records, and technical SOPs to generate evidence-grounded root-cause investigations.

### What ForgeSight SHOULD Automate
- Automated retrieval and cross-correlation of visual evidence, MES batch history, machine logs, and SOP documents.
- Multimodal feature extraction (identifying visual defects from AOI images and matching with feeder change timestamps).
- Evidence-grounded root-cause hypothesis ranking based on historical defect patterns and machine telemetry.
- Automated generation of structured incident investigation reports.

### What ForgeSight SHOULD NOT Automate (Human-in-the-Loop Boundaries)
- **High-Impact Physical Actions**: Placing entire factory component lots on quality hold without engineer sign-off.
- **Machine Parameter Changes**: Altering reflow furnace thermal profiles or placer nozzle force settings directly on live production machinery.
- **Supplier Penalties**: Initiating formal Supplier Corrective Action Requests (SCAR) without manager review.
