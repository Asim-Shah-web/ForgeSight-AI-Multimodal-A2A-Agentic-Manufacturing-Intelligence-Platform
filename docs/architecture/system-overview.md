# System Overview

## Purpose

ForgeSight AI is a multimodal manufacturing intelligence platform that enables specialized AI agents to collaborate on visual quality inspections, root-cause investigation, and reporting.

## Key Capabilities

1. **Visual Quality Inspection**: Automated vision analysis of component defects (e.g. solder bridges, missing parts).
2. **Multimodal Incident Context**: Combines text notes, high-res images, manufacturing PDFs, and line telemetries.
3. **Agent-to-Agent (A2A) Collaboration**: Specialized agent micro-roles communicating via protocol-standardized message frames.
4. **Model Context Protocol (MCP)**: Dynamic tool & resource invocation for QMS, ERP, and maintenance databases.
5. **Knowledge Retrieval (RAG)**: SOP, defect taxonomy, and equipment manual vector retrieval.
