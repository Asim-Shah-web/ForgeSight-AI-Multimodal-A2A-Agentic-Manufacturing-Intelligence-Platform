# A2A Learning Map

The complete 18-step progression for mastering the Agent-to-Agent (A2A) protocol:

1. `01-why-agent-to-agent.md`: The problem A2A solves.
2. `02-a2a-mental-model.md`: Core protocol concepts & service boundaries.
3. `03-agent-cards.md`: Agent identity & capability definitions.
4. `04-agent-discovery.md`: Finding & dynamic discovery of agents.
5. `05-tasks.md`: Task submission & state tracking.
6. `06-task-lifecycle.md`: Task states and transitions.
7. `07-messages.md`: Message structures and framing.
8. `08-parts.md`: Multimodal message parts (text, inline image, blob).
9. `09-artifacts.md`: Task execution outputs and results.
10. `10-streaming.md`: Real-time task progress and token streaming.
11. `11-push-notifications.md`: Asynchronous task completion callbacks.
12. `12-authentication.md`: Securing A2A endpoints.
13. `13-errors-and-retries.md`: Failure modes, error codes, and resilience.
14. `14-agent-discovery-patterns.md`: Registry vs peer discovery.
15. `15-a2a-vs-mcp.md`: Agent communication vs Tool invocation.
16. `16-a2a-security.md`: Trust boundaries & payload encryption.
17. `17-a2a-production-patterns.md`: Scaling, tracing, and monitoring.
18. `18-a2a-project-integration.md`: Bringing A2A to ForgeSight AI.
