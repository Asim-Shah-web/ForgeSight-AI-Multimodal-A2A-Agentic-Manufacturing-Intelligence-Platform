# ForgeSight AI Learning Harness

This directory contains the protocol learning notes, concept explanations, and implementation harnesses for **Agent-to-Agent (A2A), Model Context Protocol (MCP), RAG, Computer Vision, and Multimodal Agentic Systems**.

## Learning Structure

- `a2a/`: Step-by-step notes covering every A2A protocol primitive.
- `mcp/`: Concept notes and tool/resource mechanics for MCP.
- `rag/`: Dense retrieval, reranking, and domain knowledge ingestion.
- `computer_vision/`: Preprocessing, detection, classification, and visual evidence modeling.
- `multimodal/`: Image, text, and PDF fusion logic.
- `backend/`: FastAPI, Pydantic, and async service boundaries.
- `frontend/`: React components, streaming visualization, and operational UI.
- `production/`: Observability, tracing, metrics, and evaluation harnesses.
